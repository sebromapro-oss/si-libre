# SI Libre

Plateforme publique d'entraînement en Sciences Industrielles.

## Accès

- CAP : `/cap/`
- Bac Pro : `/bacpro/`
- BTS : `/bts/`

Les trois versions proposent des missions progressives, des aides graduées, des micro-cours après réponse et une logique de consolidation.

## Données

Le site fonctionne sans compte élève et ne nécessite pas de données personnelles.

## Publication

Le dépôt est dédié uniquement à la version publique de SI Libre. Le dépôt de développement principal reste privé.
